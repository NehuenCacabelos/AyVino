# 📥 Bandeja de Entrada (Inbox de Ideas)

Este directorio es el buzón de entrada rápido de **AyVino** para volcar notas sin procesar, bocetos, ideas de producto, dudas de arquitectura o notas de cata preliminares.

---

## 🎯 ¿Cómo usar esta carpeta?

1. **Captura inmediata y sin fricción:**
   - Si se te ocurre una mejora para el frontend, un algoritmo para maridajes o un vino que descubriste, crea un archivo aquí (ej: `idea-filtro-acidez.md` o `nota-malbec-patagonico.md`).
   - No te preocupes por el formato, la prolijidad o las etiquetas en este momento; el objetivo es no perder la idea.

2. **Uso de plantilla opcional:**
   - Puedes usar la plantilla [[tpl_idea]] si deseas estructurarla rápidamente.

3. **Revisión y Procesamiento:**
   - En cada iteración o sesión de documentación, revisa las notas de esta carpeta.
   - Si la idea se descarta, bórrala o márcala como descartada.
   - Si es una definición de dominio (vino, región, maridaje), dale formato según [[Styleguide]], aplica la plantilla correspondiente y muévela a `01_Dominio/`.
   - Si es un requerimiento técnico o tarea de ingeniería, incorpórala a [[Especificacion_Requerimientos]] o [[Roadmap]] y muévela a `02_Proyecto/`.
